loading-progress

The thin red line along the top. It cannot know how long anything takes — it creeps, fast then slow, and fills only once the page is ready.

Ready means: loaded, and nothing busy

These cards wait for their "data" — as long as the box at the top left says — marked aria-busy="true" until then. The bar waits for them too — on the first load and after every page change. Load this page again to watch it.

Links

A link to another page of this site starts the bar; the next page carries on from where it was. Timing goes on the link, or on anything above it.

  • Page 1 this page, loaded afresh — no ?page, no #hash
  • Page 2 the defaults
  • Page 3 -duration="6000": creeps three times slower
  • Page 4 -easing="linear": the same speed all the way to 90%
  • Page 5 -delay="2000": shows only if not ready within 2 s — with a wait under 2 s, it never shows
  • Page 6 -finish="1200": fills slowly once ready
  • Page 7 inside data-pg-loading-progress="off": the click starts nothing — the next page's own first load still shows its bar
  • #links this page: no bar
  • Page 8 in a new tab: no bar here

Forms

A form sent the browser's own way starts it too, and takes the same attributes — on the form, or on the button that sends it. It opens a new page, which starts at the top — or, with action="#forms" as here, at this form.

Your own jobs

startLoading() starts it and returns done() — for a button that fetches data, "load more", a filter. No page change, so the page stays where it is. Several at once: it fills when the last one is done.
